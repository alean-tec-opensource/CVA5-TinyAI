# Home
Welcome to the CVA5-TinyAI Open Source project. The idea for this project is to add to extend the **OpenHW CVA5** core with an AI capable core like the the on epresented in this paper: [e-GPU: An Open-Source and Configurable RISC-V Graphic Processing Unit for TinyAI Applications](https://arxiv.org/abs/2505.08421).

The CVA5-TinyAI repository holds the documentation, source files and how-to instructions on how-to combine CVA5 and GPU/NPU cores from their respective repos. The goal is to support those project by adopting them and contributing back.

## Governance
Refer to the [Governance](/CONTRIBUTING.md#governance--decision-making) and the [Contribute Code](CONTRIBUTING.md#how-to-contribute-code) sections if the CONTRIBUTING.md. Governance underlines how we take actions and make decisions, and also how to operate withon the group's mission and vision. 

### Mission
To foster open source hardware, world wide, royalty free, technological sound and relevant to society.

### Vision
To contribute to top-tier open-source hardware projects hosted by organizations such as the Eclipse Foundation/OpenHW Foundation, RISC-V International, CERN, or IEEE.

### Decision Making process
In support of out Mission and Vision, our decision making process will rely on a Technical Steering Committee (TSC). The TSC is responsible for defining, enforcing, and arbitrating the decision-making process.
